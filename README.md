# datasciencecoursera-repo

## Electric-power-consumption

This project is an exploratory data analysis for two days of household power consumption using Base R plotting system.

I focused on data cleaning by merging text columns into a proper POSIXct time sequence to map minute-by-minute energy usage.

Two separate folders for my R scripts and the final exported PNG figures.

It includes four baseline plots covering macro power distributions, voltage stability, and layered zone sub-metering data.
